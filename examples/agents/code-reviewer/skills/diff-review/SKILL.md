# Diff Review

物化进 child 工作目录的 `.claude/skills/diff-review/SKILL.md`。

## 何时使用

收到「审查这段改动 / 这个 PR / 这个 diff」类请求时。

## 审查维度(逐项过)

1. **正确性**:逻辑、边界、错误处理、空值/越界。
2. **并发**:共享状态、锁、竞态、上下文取消。
3. **安全**:输入校验、注入、越权、密钥/PII 泄露。
4. **可维护性**:命名、重复、可简化、与周边代码一致性。
5. **测试**:改动是否有对应测试;断言是否覆盖关键路径。

## 输出格式

按严重程度分组,每条 `文件:行号` + 具体修改建议:

```
Blocker:
- path/to/file.go:42 — <问题与修法>
建议:
- ...
nit:
- ...
总体结论:<一句话>
```
