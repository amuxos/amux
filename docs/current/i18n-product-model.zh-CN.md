# 产品语言模型

[English](i18n-product-model.md) | [简体中文](i18n-product-model.zh-CN.md)

状态：全产品迁移的目标规格。管理卡片已支持两种语言，其余入口正在迁移；本文件不代表已完成全部覆盖。

## 范围

产品拥有的界面文案支持英文（`en`）和简体中文（`zh-CN`）：飞书卡片和通知、CLI 帮助和供人阅读的操作反馈、终端界面标签，以及桌面窗口、菜单、对话框、通知和无障碍标签。成功页面已翻译而错误或权限提示仍未翻译，不算完成覆盖。

Agent 回复、用户内容、名称、路径、ID、可执行命令名、flag 名、协议字段、JSON 输出和第三方原始诊断保留原值，围绕这些值的产品提示需要翻译。不得通过替换已渲染文本中的子串翻译用户内容或 JSON 输出。

## 语言选择

- 飞书沿用机器人与用户共同隔离的偏好。私聊入口支持跟随客户端、英文和简体中文；共享卡片使用各自查看者的客户端语言，一个人的偏好不能改变其他人的显示。产品拥有的纯文本降级消息显式解析目标接收者偏好。
- CLI 语言按单次调用隔离：显式语言选项优先于 `AMUX_LANGUAGE`，再依次读取 `LC_ALL`、`LC_MESSAGES`、`LANG`，最后回退英文。结构化输出、补全标识符和退出码不随语言改变。切换语言不要求重启 Hub 或 Runtime，也不修改 Agent 环境。
- 桌面端支持跟随客户端、英文和简体中文，并在本机持久保存用户偏好。切换后渲染界面和原生菜单立即更新，重启后仍生效。

## 文案资源和渲染契约

使用显式产品文案条目和统一的语言归一化、回退规则。资源按拥有文案的界面组织，不要求无关入口互相依赖 UI 实现。每条文案必须包含两种语言，插值参数一致；遗漏条目和意外硬编码文案应被覆盖检查发现。

在展示边界选择语言，保留错误的诊断原因及机器可读值。多用户 Hub 和 Runtime 不得修改进程级全局语言。格式化和截断操作作用于已本地化的产品文案，不能翻译字面量参数。

## 验收

会话卡片迁移覆盖状态与耗时、用量标签、问题与补充标题、计划、执行记录、子任务摘要、
处理过程与最终结果标题、完整输出入口及超长降级提示。按查看者语言显示的文案必须在
CardKit 创建、插入、替换、流式更新及旧卡片发送路径中保留。最终结果标题与 Agent
流式正文分开，避免仅更新正文时覆盖翻译或翻译 Agent 输出；不追溯改写已发送的历史
卡片。本项在实现验证完成前仍为目标。

验证两种语言、不支持语言的回退、偏好持久化和隔离，以及成功、失败、空状态、加载中的产品文案和原有数据载荷。飞书验证必须覆盖原生卡片约束，不能只检查 JSON 是否能解码；独立回调控件不得携带仅表单内允许的属性。CLI 对比两种语言的 JSON、命令行为及退出码。桌面端覆盖无需刷新切换语言和原生菜单更新。
