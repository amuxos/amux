# 飞书群设置实现计划

[English](2026-09-16-feishu-group-settings.md) | [简体中文](2026-09-16-feishu-group-settings.zh-CN.md)

本文记录[群设置规格](../specs/2026-09-16-feishu-group-session-defaults-design.zh-CN.md)
对应的实现和验证范围。实现采用 Go、modernc SQLite、既有飞书卡片和 Session 启动链路。
发行版专用的 L4 夹具和环境证据保留在发行版仓库中。

## 实现顺序

1. 增加带版本的群配置、原子 workspace 更新、连续会话锚点及输入/输出入口关联。
   读取不自动启用群配置。测试完整往返、Bot/群独立、过期更新、创建竞争和重启。
   Pack 卸载检查覆盖群引用。
2. 解析完整且一致的启动策略，包括 Profile、Runtime、模型、思考强度、工作区和隔离要求。
   保留显式选择及已有 Session 快照；串行处理首次连续会话创建与模式转换。
   连续会话输出直接发群，退役或重启后恢复在途输出。普通执行使用 passthrough，
   必须隔离时固定 linux-dac，不改变执行授权。
3. 增加负责人专用、校验作用域签名和版本的管理卡片、自然语言及 workspace 命令，
   以及本机运维 CLI。复用执行选择器，区分当前会话设置和将来默认值，保留既有访问
   权限和群值守管理入口。
4. 在共享实验功能页加入默认关闭的实例级开关。配置原子保存，展示待重启状态，
   旧卡片缺失字段时保留原值，本机 CLI 加载磁盘配置。关闭时阻止编辑和已配置群的
   新任务，保留在途输出及关联；验证未配置群和私聊的原有 Bot 行为。
5. 更新产品模型和双语生成参考；编辑阶段跑聚焦测试，冻结后运行完整门禁。
   L4 使用真实飞书消息及 Runtime 状态，恢复测试配置，只清理本轮创建的 Session。

## 需保留的验收证据

记录两群路由、连续会话复用与重置、完整模型/Runtime/思考强度选择、普通和隔离执行
UID、两个隔离身份的双向 DAC 拒绝、隔离不可用及 helper 故障时的拒绝，以及 Hub 重启后
直接群输出。测试默认关闭拒绝、保存但未重启、开启后执行、恢复关闭状态。

构建身份、真实检查和环境限制单独记录。指定模型成功启动但没有最终回复，不算回复
链路通过；用支持的对照模型补测，并同时报告两种结果。公共产物不包含凭据、安装数据库
或私有环境信息。项目 AGENTS.md/CLAUDE.md 保持版本化文档。
